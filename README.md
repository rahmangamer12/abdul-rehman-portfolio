# Abdul Rehman — Portfolio

Personal portfolio and CV of **Abdul Rehman**, AI Web Developer & Agentic AI Engineer.
Co-Founder of [Undercraft Studio](https://undercraftstudio.com) · Founder of [Velcarro](https://velcarro.com).

**Live:** https://abdulrehman-undercraft.vercel.app

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Motion · next/font · next/image · deployed on Vercel.

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

- Content lives in `src/lib/data.ts` (projects, services, stack, process).
- Project screenshots are in `public/work/`.
- The CV page is `/cv`; `public/Abdul-Rehman-CV.pdf` is printed from it with Playwright.
